## 1. What is Director's Eye?

Director's Eye is a **personal AI film director** — a web application that transforms a plain-language cinematic idea into a fully structured **Scriptment** (a narrative film blueprint) complete with:

- **Story beats** with shot types, emotional tones, and camera recommendations
- **Storyboard frames** generated by AI image models
- **Shoot lists** with exact camera settings calibrated to your gear
- **Production schedules** optimized by lighting conditions
- **Genre exploration** — see how the same concept plays across 6 emotional arcs

### Who is it for?

- **Solo filmmakers / indie directors** planning their next shoot
- **Film students** learning story structure and shot planning
- **Content creators** needing quick production breakdowns
- **Travel filmmakers** wanting to avoid cliché tourism visuals

### Core Philosophy

~**80% of the scriptment is deterministic code**, not AI. The beat template engine defines act structure, shot variety, emotional pacing, lens assignments, and grammar rules. The LLM (Large Language Model) is only invoked for the ~20% that genuinely needs creativity: **descriptions and motivations**. This makes generation cheaper, faster, and more consistent.

### Data Flow — Scriptment Generation

```
User Concept (e.g. "A 60-second film about solitude at dawn")
    │
    ▼
┌─────────────────────┐
│  Concept Enricher   │  ← Rule-based keyword extraction, mood/time inference

└─────────┬───────────┘

          ▼
┌─────────────────────┐
│  BeatTemplateEngine │  ← Generates 6-8 beats with shot types, lenses,
│  (deterministic)    │     emotional tones, narrative functions
└─────────┬───────────┘
          │ structured beats (no descriptions)
          ▼
┌─────────────────────┐
│  Constraint Mode    │  ← Thins beats per mode (solo_crew=5, guerrilla=5, etc.)
│  (deterministic)    │
└─────────┬───────────┘
          │ constrained beats
          ▼
┌─────────────────────┐
│  LLM (one call)     │  ← ONLY creative part: writes descriptions + motivations

└─────────┬───────────┘
          │ beats + LLM-written descriptions
          ▼
┌─────────────────────┐
│  Grammar Validator  │  ← Fixes shot variety, lens assignments, tone, relevance
│  (deterministic)    │     If relevance is too low → auto-retry with stronger prompt

          ▼

│  (external API)     │     One image per beat
└─────────┬───────────┘

          ▼
```

## 5. AI Pipeline — Detailed Breakdown

### 5.1 Concept Enricher (`services/concept_enricher.py`)

A **zero-cost rule-based system** that:

1. **Extracts keywords** using YAKE (unsupervised keyword extraction, 2MB) or regex fallback
2. **Infers time of day** from keyword matching (dawn/sunrise → `golden_hour_am`, sunset/dusk → `golden_hour_pm`, etc.)
3. **Infers mood** from keyword matching (lonely/solitude → `melancholy`, hope/triumph → `hopeful`)
4. **Infers location** from keyword matching (harbor/boat → `harbor`, city/urban → `city`)
5. **Expands sparse concepts** — maps subject keywords to rich scene descriptions
6. **Anti-tourism mode** — replaces tourism language (`beautiful`→`honest`, `paradise`→`everyday`, `white sand`→`weathered concrete`) and strips travel-brochure keywords

### 5.2 Beat Template Engine (`services/beat_engine.py`)

The **heart of the deterministic pipeline**. Based on two established frameworks:

- **Reagan et al.'s six emotional arcs** (Springer, 2016) — quantitative analysis of narrative emotional trajectories
- **Save the Cat! beat structure** (Blake Snyder / Noam Kroll) — 15-40 beat story structure

#### Emotional Arcs

| Arc | Curve | Example Films |
|---|---|---|
| **Rags to Riches** | Steady rise 📈 | *The Pursuit of Happyness*, *Rocky* |
| **Tragedy** | Steady fall 📉 | *Requiem for a Dream*, *The Godfather Part III* |
| **Man in a Hole** | Fall → Rise 📉📈 | *The Lion King*, *Finding Nemo* |
| **Icarus** | Rise → Fall 📈📉 | *Wall Street*, *Scarface* |
| **Cinderella** | Rise → Fall → Rise 📈📉📈 | *Cinderella*, *The Matrix* |
| **Oedipus** | Fall → Rise → Fall 📉📈📉 | *Million Dollar Baby*, *There Will Be Blood* |

Each arc has a **7-point valence curve** (0.0-1.0) mapped across the narrative: Act I start → Act I end → Act IIa → Midpoint → Act IIb → Act III start → Finale.

#### Beat Generation

The engine generates 6-8 beats per scriptment with:
- **Narrative function** from the Save the Cat beat sheet (Opening Image, Catalyst, Midpoint, All Is Lost, Finale, etc.)
- **Shot type** — 7 options (Establishing, Wide, Medium, Close-up, ECU, POV, Aerial), ensured no two consecutive beats share the same type
- **Emotional tone** — derived from valence curve position (Melancholy, Tense, Contemplative, Peaceful, Hopeful, Joyful, Transcendent)
- **Lens assignment** — 33mm for wide shots, 55mm for close-ups, Find X9 (phone camera) for POV/Aerial
- **Act structure** — balanced across 3 acts (Act I: 20-35%, Act II: 45-55%, Act III: 20-35%)

### 5.3 Unified LLM Client (`services/llm.py`)

Auto-detects available providers in this order (cheapest first):

```python
detection_order = ["deepseek", "grok", "openai", "gemini"]
```

**LLM Call — Descriptions Only:**

Instead of sending the full concept to generate everything, the client:
1. Builds a minimal prompt from the beat engine structure
2. Sends only the beat numbers + shot types + lens info as context
3. Requests ONLY descriptions and motivations per beat
4. Parses the JSON response and merges descriptions back into the beat objects

This approach:
- **Reduces token usage by ~60%** compared to full-generation prompts
- **Ensures structural consistency** — the LLM can't invent wrong shot types or lenses
- **Costs ~$0.001-0.005 per scriptment** on DeepSeek/Grok

**Provider-specific details:**

| Provider | Model | Endpoint | Cost Estimate |
|---|---|---|---|
| DeepSeek | `deepseek-v4-flash` | `api.deepseek.com/v1` | ~$0.002/project |
| Grok (xAI) | `grok-3` | `api.x.ai/v1` | ~$0.003/project |
| OpenAI | `gpt-4o-mini` | `api.openai.com/v1` | ~$0.005/project |
| Gemini | `gemini-2.5-flash` | Google API | Free tier available |

### 5.4 Storyboard Frame Generation (`models/sdxl_turbo.py`)

Despite the file name, this uses **external APIs only** — no local ML models.

**Strategy:**
1. **Try Gemini** (gemini-2.5-flash-image) if `GEMINI_API_KEY` is configured
2. **Fall back to Pollinations** (free, no API key needed)

**Prompt construction is minimal by design:**
- The LLM-written description (already anchored to user's concept) carries ALL creative signal
- Only technical framing and lens characteristics are added structurally
- No hardcoded color palettes, lighting recipes, or setting textures
- This prevents overriding the concept's unique visual identity

```python
# The actual prompt template:
prompt = (
    f"cinematic storyboard frame, film still, "
    f"{base_framing}, "       # e.g. "medium shot, waist up, intimate framing"
    f"{base_lens}, "           # e.g. "portrait compression, creamy bokeh"
    f"{emotional_tone.lower()} mood, "
    f"scene: {description}, "  # The LLM-written description leads everything
    f"35mm film grain, photorealistic, high detail, "
    f"natural skin tones, "
    f"no text, no watermark, no UI elements"
)
```

### 5.5 Grammar Validator (`services/grammar_validator.py`)

A **deterministic post-generation validator** that fixes common issues without requiring LLM re-generation:

| Rule | Auto-Fix |
|---|---|
| **Shot variety** | No two consecutive beats may share the same shot type |
| **Lens assignment** | POV/Aerial → Find X9, ECUs → 55mm, rest → 33mm |
| **Emotional tone** | Re-computed from arc position if LLM's tone differs |
| **Act balance** | Warnings if any act deviates from expected beat count range |
| **Description quality** | Strips markdown, enforces minimum length, removes boilerplate |
| **Concept relevance** | Checks if LLM descriptions match user's concept keywords — if relevance critically low, triggers LLM re-generation with reinforced prompt |

### 5.6 Mood Grader (`services/mood_grader.py`)

Optional color grading for storyboard frames using Pillow LUTs:

| Grade | Effect | Typical Use |
|---|---|---|
| **Natural** | Identity (no change) | Default |
| **Teal/Orange** | Teal shadows, warm highlights | Action/thriller |
| **Warm Golden** | Boosted red/green midtones | Drama, golden hour |
| **Cool Blue** | Reduced red, boosted blue | Melancholy, night |
| **Desaturated** | Near-monochrome | Gritty, noir |
| **High Contrast** | S-curve contrast | Dramatic, edgy |

## 9. Shoot Modes

Each mode constrains the beat template **before** LLM invocation — reducing both generation cost and production complexity.

| Mode | Max Beats | Token Savings | Constraints |
|---|---|---|---|
| **Normal** 🎬 | 8 | 0% | Full creative freedom |
| **Solo Crew** 🎒 | 5 | ~37% | 2 people max, one lens, available light, no complex camera moves |
| **Minimal** 📦 | 6 | ~25% | 5 locations max, natural light only, no gimbal/dolly |
| **Guerrilla** 🏃 | 5 | ~37% | Single 33mm prime, handheld, available light, stealth run |
| **Studio** 💡 | 7 | ~12% | Controlled environment, artificial light only, tripod-heavy |

**Implementation (`services/modes.py`):**

Each mode applies specific filters:
- **Solo Crew:** Removes POV, Aerial, and ECU shots; forces 33mm lens; removes complex camera movements
- **Minimal:** Restricts location diversity; removes Aerial and POV shots; natural light only
- **Guerrilla:** Forces ALL shots to 33mm lens; handheld only; street photography aesthetic
- **Studio:** Interior-only (converted if needed); tripod and artificial light only; removes POV/Aerial

## 10. Emotional Arcs & Genre Explorer

The **Genre Explorer** (`/api/explore/genres`) is the most impressive demo feature: one concept, 6 completely different films, generated concurrently.

### How It Works

```python
# All 6 arcs run in parallel via asyncio.gather
async def explore_genres(request):
    enriched = enricher.enrich(request.concept)
    
    async def generate_for_arc(arc):
        engine = BeatTemplateEngine(arc=arc)
        beats = engine.generate_template()
        beats = apply_constraints(beats, mode)
        beats = await client.generate_descriptions_only(beats, enriched.expanded, ...)
        return { "arc": arc.value, "scriptment": ... }
    
    # CONCURRENT — total time ≈ time for 1 arc
    results = await asyncio.gather(*[
        generate_for_arc(arc) for arc in EmotionalArc
    ])
```
